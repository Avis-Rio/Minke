<h2 id="cn-v0.9.0">本次更新</h2>

- **升级至 `dsh-v0.2.1-rc.2`**：同步新版 Search / Fetch API、模型凭据与推理档位设置，以及插件兼容性和长对话体验改进。
- **统一桌面设置**：快捷键在 General 中查看和编辑，终端与文件预览使用原生字体设置；窗口语言、主题、全屏和右键菜单与 DSH 保持一致。
- **改进工作区与浏览器**：右侧栏“＋”使用原生 Start 页，Files 接入原生远程 API 和系统打开操作；持久浏览器继续保留已有登录状态，Agent Browser 使用独立临时会话。
- **修复本地模型上下文**：LM Studio 和 Ollama 使用实际加载模型的上下文容量；推理失败后停止自动重试和重新加载，可通过下一次手动请求恢复。
- **完善退出与故障恢复**：存在运行任务或提醒时退出会先确认；致命故障支持重启、插件安全模式和诊断文件，便于恢复与排查。
- **改善更新与开发启动**：已验证的更新包可留待稍后安装，重启后仍可复用；开发版使用独立数据目录，并复用未变化的构建产物。

**升级提示**：升级前建议备份 Data Home。已有快捷键和终端字体会迁移到原生设置，并保留旧配置；已设置的 DSH 字体优先。第三方插件如提示不兼容，请更新后再启用。详见[升级说明](https://github.com/lencx/Minke/blob/v0.9.0/docs/dsh-upgrade.md)。

<h2 id="en-v0.9.0">What's new</h2>

- **Upgrade to `dsh-v0.2.1-rc.2`**: Bring in the new Search / Fetch API, model credential and reasoning settings, and improvements to plugin compatibility and long conversations.
- **Unify desktop settings**: View and edit shortcuts in General, and use native font settings for terminals and file previews. Window language, theme, fullscreen behavior, and context menus follow DSH.
- **Improve workspaces and browsers**: Use the native Start page from the right sidebar's “+” button. Files use native remote APIs and system open actions. Persistent Browser retains existing sign-ins, while Agent Browser uses separate temporary sessions.
- **Fix local model context**: Read the effective context capacity of loaded LM Studio and Ollama models. Failed inference stops automatic retries and model reloads; a subsequent manual request can recover.
- **Improve shutdown and recovery**: Confirm quitting when tasks or reminders are active. Fatal failures offer restart, plugin safe mode, and diagnostic files to help recovery.
- **Improve updates and development startup**: Keep verified update packages for later installation, including across restarts. Development uses separate data directories and reuses unchanged build outputs.

**Upgrade notes**: Back up Data Home before upgrading. Existing shortcuts and terminal fonts migrate to native settings while retaining the old configuration; existing DSH font settings take precedence. Update incompatible third-party plugins before enabling them. See the [upgrade guide](https://github.com/lencx/Minke/blob/v0.9.0/docs/dsh-upgrade.md).
